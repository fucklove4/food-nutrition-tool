# 食物营养分析工具

输入身高、体重、年龄、性别与目标（减脂 / 增肌），自动计算 BMI 与每日营养目标，
推荐对应食材、生成一日三餐配餐，并可由 AI 给出个性化饮食建议。

前端为纯 HTML + CSS + 原生 JavaScript（ES Module，无框架无构建）；
后端是单个 FastAPI 文件，仅用于代理 DeepSeek —— **API 密钥不落在前端**。

数据集来自《中国食物成分表标准版（第 6 版）》，共 **1,677 种食物 / 15 个大类**。

---

## 功能

| 功能 | 说明 |
|---|---|
| **营养画像** | BMI（中国成人标准）、基础代谢（Mifflin-St Jeor）、目标热量、蛋白/碳水/脂肪分配 |
| **食材推荐** | 分「优质蛋白 / 蔬菜菌藻 / 水果 / 主食薯类」，再按来源与部位分栏 |
| **食物搜索** | 查任意食物，支持拼音首字母（`jxpr` → 鸡胸脯肉），无需先填表单 |
| **一日三餐** | 按目标热量拆成三餐 + 加餐，给出食材与克数，份量随目标自动缩放 |
| **优缺点 / 注意** | 由营养成分按阈值推导（原书无此字段），结论可追溯到具体数值 |
| **收藏 / 历史 / 分享** | 全部走浏览器本地，不上传、无账号 |

## 本地运行

需要一个本地服务器（浏览器禁止 `file://` 读取本地 JSON）。

**Windows 一键启动**：双击 `start.bat`，用完双击 `stop.bat`。
`preflight.bat` 是部署前的密钥安全检查。

> 三个 .bat 都是纯 ASCII 英文内容。这是刻意的：`chcp 65001` + 中文的批处理
> 会让 cmd.exe 按字节偏移解析文件时错位，把命令切断（`timeout` 被读成 `imeout`）。

**手动方式**：

```bash
# 前端
python -m http.server 8788 --bind ::

# 后端（可选，仅 AI 建议需要）
pip install fastapi uvicorn requests python-dotenv
cp .env.example .env      # 填入你的 DeepSeek API Key
python -m uvicorn server:app --port 8000
```

打开 <http://localhost:8788/>

> `--bind ::` 让服务同时监听 IPv4 与 IPv6。若只绑定 `127.0.0.1`，
> 在 `localhost` 优先解析到 `::1` 的系统上浏览器会连接失败。

**不启动后端时，除「AI 建议」外的功能全部可用。**

## 数据说明

- 数值均为**每 100 g 可食部**；卡片额外标注「参考份量 ≈ 多少 kcal」
- 使用已修正原书错误的版本：原书薯类部分（048004–048084）能量 kcal/kJ 两列印反，
  已通过 `kcal × 4.184 ≈ kJ` 与 Atwater 系数（4/9/4）交叉校验定位并修正
- 数据由视觉模型识别原书表格截图转换而来，**可能存在识别误差**
- 缺失值有三种记号：`—`（未检出）、`Tr`（痕量）、`""`（空）

### 已知的数据限制

- **不含 GI（升糖指数）**。主表无该字段；独立 GI 表虽有 259 条但无食物编码，
  实测精确匹配率仅 4.6%，因此**不接入推荐逻辑**，避免输出虚假精确的结论
- **不含嘌呤**，痛风相关提示仅按食物类别保守标注
- `carotene`（53.9%）、`vitaminE2`（56.2%）等字段覆盖率偏低，未纳入评分

## 「优缺点 / 禁忌」怎么来的

原书**没有**这些字段，本项目也没有编造，而是**按营养成分阈值推导**，
阈值取自本数据集的真实分布：

| 标签 | 阈值 | 依据 |
|---|---|---|
| 高蛋白 | 蛋白质 ≥ 20 g/100g | p90 ≈ 24 |
| 高纤维 | 膳食纤维 ≥ 6 g/100g | p90 ≈ 5.8 |
| 低热量密度 | 热量 < 100 kcal/100g | 中位数 ≈ 118 |
| 高钠（注意） | 钠 > 600 mg/100g | p90 ≈ 561 |
| 高胆固醇（注意） | 胆固醇 > 300 mg/100g | p95 ≈ 200 |

## 项目结构

```
├── index.html          页面结构
├── css/style.css       移动优先样式
├── js/
│   ├── rules.js        纯计算层：阈值、类型判定、优点推导、评分、BMI/能量目标、搜索
│   ├── planner.js      纯计算层：一日三餐配餐（份量缩放 + 坐标下降优化）
│   ├── store.js        纯逻辑层：收藏 / 历史 / 分享链接编解码
│   └── app.js          界面层：DOM 渲染与事件、AI 调用
├── data/foods.json     1,677 条食物数据（约 540 KB）
├── server.py           FastAPI 后端：代理 DeepSeek
└── 启动.bat / 停止.bat / 部署前检查.bat
```

`rules.js` / `planner.js` / `store.js` **不依赖 DOM**，因此可在 Node 中直接用真实数据测试。
